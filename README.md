## 01_basics — create local files

### What it does

`01_basics/main.tf` creates:

- `example1.txt` (a single file)
- `count-0.txt`, `count-1.txt`, `count-2.txt` (using `count`)
- `sensitive.txt` (using `local_sensitive_file`, which marks the content as sensitive in Terraform output/state display)

### Files to know

- `01_basics/provider.tf`: pins the provider version (`hashicorp/local` `2.6.2`)
- `01_basics/main.tf`: resources you are managing
- `01_basics/.terraform.lock.hcl`: dependency lock file (generated by `terraform init`)
- `01_basics/terraform.tfstate`: Terraform state (tracks what was created)
- `01_basics/plan`: a saved plan file (generated by `terraform plan -out ...`)

### Run it (recommended workflow)

From the repo root:

```powershell
# Initialize providers for this section
terraform -chdir=".\01_basics" init

# Show the execution plan
terraform -chdir=".\01_basics" plan

# (Optional) Save a plan to a file
terraform -chdir=".\01_basics" plan -out ".\plan"

# Apply changes (create/update files)
terraform -chdir=".\01_basics" apply

# Or apply a previously saved plan file
terraform -chdir=".\01_basics" apply ".\plan"
```

### Clean up (destroy)

```powershell
terraform -chdir=".\01_basics" destroy
```

## Common Terraform commands

Run from the repo root (or add `-chdir=".\01_basics"` to target that folder):

```powershell
terraform -version
terraform fmt -recursive
terraform validate
terraform init
terraform plan
terraform apply
terraform destroy
terraform show
terraform state list
```
